# MOEW (MOdel previEW)

### Instant Preview for 3D/2D Model Assets

Fast and lightweight preview for digital model assets on Windows.

Supports formats such as `VRM`, `PMX`, `FBX`, `Live2D`, `glTF`, and more.

MOEW is a lightweight Windows application that lets you instantly preview 3D and 2D model assets directly from File Explorer, without launching editors like Unity or Blender.
